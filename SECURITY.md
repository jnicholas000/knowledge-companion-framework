# Security Policy

## Supported Versions

Knowledge Companion Framework is currently pre-1.0. Until versioned releases are published, security fixes are applied to the current `main` branch.

## Reporting A Vulnerability

Please do **not** report security vulnerabilities in a public issue, discussion, or pull request.

Use GitHub's private vulnerability reporting for this repository:

1. Open the repository's **Security** tab.
2. Choose **Report a vulnerability**.
3. Include a clear description, affected files or behavior, reproduction details when safe to provide, and the potential impact.

Normal bugs, documentation issues, and feature requests should continue to use public GitHub issues.

Maintainers will review private reports through GitHub Security Advisories and coordinate any necessary remediation and disclosure there.
