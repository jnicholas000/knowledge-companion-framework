# Atlas Notes Example Pack

Atlas Notes is a fictitious local command-line note application. It exists only to demonstrate how
an application pack represents architecture, a decision, a request trace, retrieval interchange,
reasoning output, delivery guidance, continuous-learning artifacts, an estimate, and an evaluation
fixture. It is not framework logic or a production implementation.

The `sources/` files stand in for repository evidence. Knowledge records cite them; the reference
validator verifies that local evidence paths exist. The learning candidate is deliberately left in
`triaged`, demonstrating that a plausible update is still not accepted knowledge.

From the repository root:

```sh
node src/cli.js validate examples/atlas-notes --strict
```
